- 💯 **Gratis**: Sin límites ni registros

### 3. Cards de Info del Archivo (4 con gradientes)

Cuando subes un archivo, aparecen 4 cards con gradientes vibrantes:

```
┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐
│ 📄 Archivo │  │ 📋 Tipo    │  │ 📏 Tamaño  │  │ 📐 Dims    │
│ Gradiente  │  │ Gradiente  │  │ Gradiente  │  │ Gradiente  │
│  Púrpura   │  │  Rosa-Rojo │  │    Azul    │  │   Verde    │
└────────────┘  └────────────┘  └────────────┘  └────────────┘
```

**Gradientes:**
- 🟣 Púrpura: `#667eea → #764ba2` (Nombre del archivo)
- 🔴 Rosa-Rojo: `#f093fb → #f5576c` (Tipo: PSD o AI)
- 🔵 Azul: `#4facfe → #00f2fe` (Tamaño: MB/KB)
- 🟢 Verde: `#43e97b → #38f9d7` (Dimensiones: px)
